# 课堂练习：进制转换

源程序：[exchange.asm](../../WORK/exchange.asm)

## 1. 完成内容

- 输入十六进制数，输出对应十进制数。
- 追加实现：输入十进制数，输出对应十六进制数。
- 题目只要求 1～2 位十六进制；本程序扩展到最多 4 位，即 `0000H`～`FFFFH`。

## 2. 转换原理

读取十六进制字符时，先将字符转换成数值 `0..15`，再重复：

```text
result = result × 16 + 当前数位
```

读取十进制字符时重复：

```text
result = result × 10 + 当前数位
```

十进制输出通过连续除以 10，把余数压栈后逆序输出。十六进制输出从最高四位开始，每次取一个半字节，并把 `10..15` 转换成 `A..F`。

## 3. 编译运行

```dos
masm exchange.asm;
link exchange.obj;
exchange
```

菜单中选择转换方向，然后输入数字并按回车。

## 4. 验证结果

| 输入方向 | 输入 | 输出 |
| --- | ---: | ---: |
| 十六进制 → 十进制 | `FF` | `255` |
| 十六进制 → 十进制 | `FFFF` | `65535` |
| 十进制 → 十六进制 | `255` | `00FF` |
| 十进制 → 十六进制 | `65535` | `FFFF` |

程序会拒绝非法字符和超出 16 位无符号数范围的输入。
